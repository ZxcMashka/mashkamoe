# Mashka Marks 1.0.3

Исправленная сборка из предоставленного `mashkamoe_1.0.0.wotmod` (внутри него была версия 3.18.1).

В 1.0.3 убрана текстовая подпись об оценочных прогнозах из ангара, боя и предпросмотра кастомизации. Сообщение об отсутствии региональных данных сохранено.

## Исправление зависания окон в 1.0.2

В 1.0.1 замена вызовов таймеров оставила обращения к несуществующим `window.mmFrame` и `window.mmTimeout`. Лог клиента подтвердил `TypeError: window.mmFrame is not a function`. Построение окна настроек прерывалось до подключения крестика закрытия; ошибка повторялась при перетаскивании. Исправлены вызовы локальных функций. Из реестра обработчиков удаляются элементы, уже убранные из DOM, включая обработчики отпускания мыши для старых кнопок.

Версия 1.0.1 снята с текущей раздачи. При обновлении удалите её `.wotmod`; историю и настройки удалять не нужно.

## Установка

Готовый файл: [mashkamarks_1.0.3.wotmod](dist/mashkamarks_1.0.3.wotmod).

1. Закройте World of Tanks.
2. Уберите предыдущий файл этого мода из `mods/<текущая версия клиента>/`, чтобы не загружать две копии.
3. Поместите **mashkamarks_1.0.3.wotmod** в `mods/<текущая версия клиента>/`.
4. Запустите клиент. Файл `.wotmod` распаковывать не нужно.

Конфигурация и история сохраняются в `mods/configs/mashka_marks/`. Перед установкой рекомендуется сохранить копию этой папки.

## Поведение

- EU, NA и Asia (`ASIA`/`SEA`/`AS`) поддерживаются выбором соответствующего регионального endpoint.
- Встроенная таблица предназначена только для EU. Кэш, соседний мод и ручная таблица принимаются только с совпадающей региональной меткой; общий источник должен содержать `realms` или `region`. Незаверенные по региону таблицы отклоняются.
- Если нет региональной таблицы или записи конкретного танка, интерфейс сообщает об отсутствии данных. Пороги не заменяются таблицей EU или модельными порогами.
- Текущий процент из досье — наблюдаемое значение. Прогноз изменения процента, требуемый урон, вероятность и расчёт будущих боёв — оценки, даже после калибровки. Они обозначаются `≈`.
- Сводка боя обрабатывается через `onPlayerSummaryFeedbackReceived`. Отдельные события скрытого урона отбрасываются по штатному `extra.isNone()`.
- При выходе из боя снимаются подписки, хук клавиш и таймеры боя. При выходе из ангара снимаются его подписки и таймеры. `fini()` освобождает оставшиеся ресурсы, поздние ответы старого поколения игнорируются. JavaScript очищает интервалы, таймеры, кадры анимации и обработчики на `unload`/`pagehide` и при повторной загрузке скрипта.

## Сборка и проверки

Python 2.7 нужен только для компиляции bytecode клиента; скрипт упаковки запускается Python 3.

```sh
cd /workspace/mashkamoe
/workspace/python2/bin/python2.7 tests/test_regressions.py
node tests/test_assets.js
python3 build.py
# Дополнительная проверка полного интерфейса: нужны Playwright и Chromium.
python3 tests/test_browser.py
# Воспроизведение исходной ошибки на коммите 79f17c6:
python3 tests/test_browser.py --baseline
```

Для другой машины задайте `PYTHON2=/путь/к/python2.7` при сборке.
Результат: `/workspace/output/mashkamarks_1.0.3.wotmod`.

Проверено: 23 регрессионных теста с заглушками клиентских API, 45 проверок JS для подписей и очистки ресурсов, синтаксис Python 2.7 и всех трёх JS-файлов, структура готового архива.

Полный интерфейс проверен в Chromium с заглушкой модели Gameface: воспроизведён сбой старой сборки, затем проверены закрытие настроек и истории, 30 циклов открытия/закрытия и переключения вкладок, перетаскивание, обновление модели и очистка. JS-исключений нет; после очистки удалённых элементов число зарегистрированных обработчиков оставалось 213 во всех циклах. Это не измерение FPS в игре.

Ограничения: клиент игры здесь не запущен; реальное переподключение, ранний выход, переходы ангар/бой, отображение в Gameface и живой ответ API Asia нужно проверить в игре. Количество проверок из старого чата к этой сборке не относится.
